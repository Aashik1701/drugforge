export for target **CHEMBL3736** (Angiotensin-converting enzyme 2, *Homo sapiens*),
vendored in this repo (see `ml/README.md`). Public data. No molecules invented,

## Pipeline (identical to every other target set)

1. Read 190 activity rows.
2. Drop rows with no SMILES: 0.
3. Parse each SMILES with RDKit; strip to the largest fragment (salt / counter-ion
   removal); canonicalise. RDKit parse failures dropped: 0.
4. Set-construction filter (docking tractability, applied to ALL paths equally,
   NOT the funnel ADMET filter): 150 <= MW <= 600, heavy atoms
   <= 45, must contain carbon. Dropped: 54.
5. Deduplicate on canonical SMILES: 122 unique molecules remain.
6. Bin by max pChEMBL across records: potent (>=7), moderate (5-7),
   weak_or_inactive (<5, or "Not Active" comment, or no pChEMBL).
7. Deterministic shuffle (seed 20260228) + take per bin: {'potent': 14, 'moderate': 13, 'weak_or_inactive': 14}.
8. Add the 4 reference ligands (canonicalised). References bypass step 4.
   If a reference also occurs in ChEMBL its row is marked `is_reference=true`.
